# Machine-learning model attribution

Budget Planner ships three pretrained model files, covering two
features. Neither is part of the initial page load: each is fetched from
this site's own origin the first time the feature that needs it is used
(`www/src/ocrWorker.js`), then run entirely in the browser via
[`rten`](https://github.com/robertknight/rten).

Voice entry shipped three speech-to-text models until it was removed for
size — 619MB, against the 28MB the two remaining features need between
them. Their attribution is preserved with the code, at the
`voice-entry-final` tag.

**The two PP-OCRv6_tiny files were converted to the `.rten` model
format**; `all-MiniLM-L6-v2.onnx` ships as the ONNX file it was
downloaded as, byte for byte. That conversion changes the serialization
format only — no change to model architecture, and no
change to trained weights. Where a license requires a statement of
modification (CC-BY-4.0 §3(a)(1)(B), Apache-2.0 §4(b)), that conversion
is the modification, and it is the only one.

The full license *text* for every component, models included, is
generated by `cargo about` into `www/static/third-party-licenses.html`
and linked from the app's privacy page.

## all-MiniLM-L6-v2

**File:** `www/static/llm/all-MiniLM-L6-v2.onnx`, `www/static/llm/tokenizer.json`
**Used for:** classifying a statement row whose direction couldn't be
resolved from its sign or a keyword as income or expense, by sentence
embedding (`crates/budget-calc/src/embed_classify.rs`)
**Source:** <https://huggingface.co/Xenova/all-MiniLM-L6-v2> (an ONNX
export of <https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2>)
