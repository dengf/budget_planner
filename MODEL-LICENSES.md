# Machine-learning model attribution

Budget Planner ships five pretrained models. None of them is part of the
initial page load: each is fetched from this site's own origin the first
time the feature that needs it is used (`www/src/ocrWorker.js`,
`www/src/voiceWorker.js`), then run entirely in the browser via
[`rten`](https://github.com/robertknight/rten).

**Four of the five were converted to the `.rten` model format** (the
files ending `.rten`); `all-MiniLM-L6-v2.onnx` ships as the ONNX file it
was downloaded as, byte for byte. That conversion changes the
serialization format only — no change to model architecture, and no
change to trained weights. Where a license requires a statement of
modification (CC-BY-4.0 §3(a)(1)(B), Apache-2.0 §4(b)), that conversion
is the modification, and it is the only one.

The full license *text* for every component, models included, is
generated by `cargo about` into `www/static/third-party-licenses.html`
and linked from the app's privacy page.

## QuartzNet15x5 (English) and Citrinet-512 (Mandarin) — NVIDIA NeMo

**Files:** `www/static/voice/quartznet15x5-fp32.rten`,
`www/static/voice/zh-citrinet-512-fp32.rten`
**Used for:** English and Mandarin voice entry
(`crates/budget-calc/src/voice.rs`, `voice_cmn.rs`)
**Source:** NVIDIA NGC —
[stt_en_quartznet15x5](https://catalog.ngc.nvidia.com/orgs/nvidia/nemo/models/stt_en_quartznet15x5),
[stt_zh_citrinet_512](https://catalog.ngc.nvidia.com/orgs/nvidia/teams/nemo/models/stt_zh_citrinet_512)

> ⚠️ **The license for these two models is unconfirmed and needs to be
> settled before launch.** Both NGC model cards state only: *"License to
> use this model is covered by the NGC TERMS OF USE unless another
> License/Terms Of Use/EULA is clearly specified."* Neither model has a
> HuggingFace mirror carrying an explicit license tag (both
> `nvidia/stt_en_quartznet15x5` and `nvidia/stt_zh_citrinet_512` return
> 401). Sibling models in the same NeMo ASR family — e.g.
> `nvidia/stt_en_citrinet_512_ls`, `nvidia/stt_zh_citrinet_1024_gamma_0_25`
> — are tagged **CC-BY-4.0** on HuggingFace, which is the family's usual
> license and permits commercial use with attribution.
>
> **Why this matters here specifically:** this app does not merely *use*
> the weights, it **re-hosts** them as static files on its own origin so
> the browser can fetch them. That is redistribution, and it needs a
> license that permits redistribution.
>
> **To resolve:** check the model card shown on NGC after accepting the
> terms (the license field is visible there but not to an anonymous
> fetch), or re-download from a source that states a license explicitly.
> If it is CC-BY-4.0, the attribution below is already sufficient — just
> delete this warning. If it is not redistributable, these two models
> have to be pulled and English/Mandarin voice entry rebuilt on a
> different one (the Cantonese path above is unaffected).

If CC-BY-4.0 is confirmed, the required attribution is:

> QuartzNet15x5 and Citrinet-512 — © NVIDIA Corporation, from the NVIDIA
> NeMo toolkit. Licensed under
> [CC-BY-4.0](https://creativecommons.org/licenses/by/4.0/).
> Converted to the `.rten` model format; no change to architecture or
> trained weights.

**Modification (either way):** the NeMo checkpoints were exported to
ONNX and converted to `.rten`.

An int8 quantized export of Citrinet-512 was measured and rejected (it
returned confidently empty transcripts); only the fp32 conversions ship.
